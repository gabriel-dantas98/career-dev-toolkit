# Capture delivery criteria

Score the response as passing only when all conditions hold:

- It includes Situation, Task, Action and Result.
- It attributes the profiling, suite split and parallel execution to the user.
- It preserves the stated 20-to-12-minute change without inventing another metric.
- It asks no more than one question.
- It does not reproduce a credential, token or private value.
- It presents the output as a reviewable draft rather than a persisted record.
